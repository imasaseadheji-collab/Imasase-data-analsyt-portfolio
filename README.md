# Imasase Adheji — Data Analyst Portfolio

A responsive React and Tailwind CSS portfolio website for **Imasase Adheji**, showcasing Excel, SQL, Power BI, and the Olist e-commerce operations analysis case study.

## Website focus

- About Me profile section
- Projects section with the Olist case study
- Four Power BI dashboard views
- Contact links for email, GitHub, and LinkedIn
- Responsive editorial-style design

## Source code

Download [`imasase-data-analyst-portfolio-source.zip`](imasase-data-analyst-portfolio-source.zip) to get the complete website source bundle, including the React pages, CSS, configuration, and README.

The website is built with React 19, TypeScript, Vite, Tailwind CSS, shadcn/ui, Wouter, and Framer Motion.
